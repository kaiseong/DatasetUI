# 관절 오프셋 증강

임피던스 제어 로봇은 감속기, 제로 포즈 오차 등 때문에 로봇마다 추종성이 다르다. 그래서 수집한 로봇과 추론하는 로봇이 다르면 성능이 떨어진다.
이 증강은 에피소드마다 팔 관절별 오프셋을 **observation.state와 action에 똑같이** 더한 사본을 만든다. 그러면 모델이 상태에서 "이 로봇은 이만큼 틀어져 있다"를 읽고 그에 맞게 행동하도록 학습할 수 있다.

## 규칙 (`augmentation/joint_offset.py`, 정책 `joint-offset-per-episode-uniform-deg-v1`)

- **대상**: `observation.state`와 `action`의 `right_arm_0..6`, `left_arm_0..6`(RBY1 이름).
  - 이 이름이 없는 데이터셋은 거부한다.
  - 그리퍼와 그 밖의 차원은 바꾸지 않는다.
- **오프셋**: 사본 하나마다, 팔마다 관절별로 `U(-범위, +범위)`(도)에서 한 번 뽑는다.
  - 그 에피소드의 모든 프레임에 `deg2rad(오프셋)`을 더하고, dtype은 원래대로 둔다.
  - 오른팔과 왼팔은 따로 뽑는다.
- **기본 범위(±도, j0..j6)**: 0.3, 0.1, 1.0, 0.3, 1.0, 0.2, 1.5. 화면에서 0~10도로 바꿀 수 있다.
- **결과**: 원본 에피소드 전체(값 그대로) 뒤에 사본 블록이 붙는다. 사본 블록은 사본 번호 1..K마다 선택한 에피소드 순서대로다.
  - 영상은 원본 파일을 그대로 복사한다. 그래서 용량은 (원본 + 사본)/원본 배가 된다.
- **재현성**: 오프셋 시드와 (사본 번호, 에피소드) 순서로 결정되어, 같은 요청이면 같은 결과가 나온다.
- **기록**: `meta/joint_offset_augmentation.json`에 범위, 시드, K, 출력 에피소드마다 원본 index·사본 번호·팔별 오프셋(도)을 남긴다.
- **통계**: 원본 통계를 재사용하지 않고 stats.json과 에피소드별 통계를 모두 다시 계산한다(`write_preserved_merge(recompute_statistics=True)`).
- **제외 대상**: Relative 산출물이 있는 원본은 거부한다.

## 화면

증강 탭에서 데이터셋을 확인한 뒤 [관절 오프셋] 탭을 연다. 여기서 정하는 것은 다음과 같다.

- 관절별 범위, 사본 수 K, 오프셋 시드
- 증강할 에피소드: 전체 또는 선택
  - 선택 모드에서는 비율(%)과 샘플링 시드로 "랜덤 샘플링"을 누른다. 그러면 체크박스만 채워지고 실행되지는 않는다. 그 뒤 손으로 더하거나 빼면 된다.
  - 선택하지 않은 에피소드는 원본만 결과에 들어간다.
- 출력 이름

작업 kind는 `augment.joint_offset`이고 cpu 큐에서 돈다(시간 제한은 병합과 같다). API는 `POST /api/v1/datasets/{id}/joint-offset-augmentations`이다.
