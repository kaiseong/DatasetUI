# 2026-09-08 변경 및 검증 안내

## 수정 내용

- 데이터셋 지문이 info.json뿐 아니라 전체 파일 내용을 포함합니다. 원본이
  바뀐 뒤 이전 검증 결과로 내보내는 것을 차단합니다.
- SSH 전송 중 작업 소유권 상실을 검사합니다. HF/PC 전송 결과가 불확실하면
  자동 재시도하지 않으며, HF 임시 저장소 정리 실패도 표시합니다.
- 주석 초안은 데이터셋 지문·프로필·에피소드별로 분리합니다. 늦게 도착한
  조회 결과와 저장 도중의 추가 수정으로 초안이 사라지는 문제를 수정했습니다.
- HF 이름 검증과 Merge 오류 응답, 잘못된 숫자 데이터의 검증 실패 보고를
  정리했습니다. v3 공유 파일의 중복 읽기·디코딩을 줄였습니다.
- Jobs는 작업 종류와 결과를 표시하고, Validate는 검사 완료를 주기적으로
  조회하여 개별 오류를 보여 줍니다.
- Next.js를 15.5.24로 업데이트하고 빌드의 타입·린트 검사를 활성화했습니다.
  Caddy는 DB·SSH 키가 있는 전체 runtime 대신 기존 caddy 하위 경로만 마운트합니다.

## 배경 증강 사용

GPU 설정은 [SAM 작업자 설치 안내](segmentation.md)를 따릅니다. 기본 Compose는
기존 서비스를 유지하며 SAM 가중치를 자동으로 받거나 라이선스에 동의하지 않습니다.

1. Library의 Augment 또는 배경 증강 메뉴에서 데이터셋을 선택합니다.
2. 에피소드·카메라를 고르고 교체 배경 또는 보호 전경 모드를 지정합니다.
3. 텍스트, 포함/제외 점, 박스로 영역을 지정합니다. 브러시로 마스크를 추가하거나
   지울 수 있습니다. 보호 영역과 교체 영역이 겹치면 보호가 우선합니다.
4. 배경 이미지를 올리고 미리보기를 생성합니다. 브러시 보정은 해당 프레임에만
   적용됩니다. 시간 방향 추적은 SAM 프롬프트로 수행합니다.
5. 원본·합성 영상과 마스크를 검토한 뒤 승인합니다. 설정을 바꾸면 기존 승인은
   해제되고 새 미리보기가 필요합니다.
6. 원하는 출력 이름을 입력하여 별도 데이터셋을 생성합니다. 같은 이름은
   덮어쓰지 않습니다. 한 번의 작업은 한 에피소드/카메라를 바꾸며 나머지를
   포함한 전체 복사본을 만듭니다. 여러 작업이 필요하면 결과를 다음 입력으로 사용합니다.

영상 미리보기는 브라우저용 H.264/yuv420p입니다. 출력의 수정 대상 영상 파일은
RGB 무손실 H.264로 인코딩하여 보호 픽셀과 공유 파일의 비대상 프레임을 보존합니다.
용량이 늘 수 있으며 사용하는 학습 환경의 하드웨어 영상 디코더 호환성은 확인해야
합니다. Parquet의 action/state/시간/주석은 변경하지 않습니다.

영상 통계는 [LeRobot의 공식 계산 규칙](https://github.com/huggingface/lerobot/blob/9724e61a26c7e24446d3734081be1b14982b78df/src/lerobot/datasets/compute_stats.py)에
맞춰 0–1 범위와 이미지 단위 count로 기록합니다. v3의 에피소드 메타데이터에
포함된 통계도 함께 갱신합니다.

## 기존 설치 업데이트 시 주의

- 배포 전에 기존 registry SQLite와 runtime을 백업하세요. Git 코드 변경만으로
  서버가 업데이트되지는 않습니다.
- 전체 파일 지문으로 전환하므로 기존 검증 통과 기록은 재사용하지 않습니다.
  Library를 다시 스캔하고 Export Gate를 다시 실행해야 합니다.
- 이전 지문에 연결된 flag·annotation·recipe 기록은 DB에서 삭제하지 않지만 새
  지문으로 자동 이전하지 않습니다. 동일한 원본이라는 확인 없이 자동 적용하면
  다른 데이터에 주석을 붙일 수 있기 때문입니다. 기존 기록을 쓰는 설치는 전환 전
  백업과 이전 계획을 확인해야 합니다. 기존 브라우저 v2 초안도 사용자/지문이
  불명확하여 자동으로 가져오지 않습니다.

## 검증 범위

회귀 테스트, TypeScript, lint, production build, Compose 구성 검사를 실행합니다.
증강 통합 테스트는 실제 작은 MP4/Parquet fixture로 API → 작업자 → 미리보기 →
승인 → 별도 데이터셋 생성까지 검사하며 **SAM 마스크 예측만 테스트 엔진으로 대체**합니다.
따라서 이 테스트가 실제 SAM 정확도나 CUDA 실행 성공을 증명하지는 않습니다.

0.3 서버에서 읽기 전용으로 확인한 GPU는 RTX PRO 6000 Blackwell 97887 MiB,
드라이버 580.173.02입니다. 이번 코드 수정으로 서버 배포나 가중치 설치는 변경하지
않았습니다. 실제 체크포인트 추론, GPU 이미지 빌드, 브라우저 클릭·재생 검증은
별도 통합 확인 항목입니다.
