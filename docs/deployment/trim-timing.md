# 앞·뒤 독립 Trim 시간

Curate → 앞뒤 정지 구간 Trim → 자동 Trim 사용에서 앞 구간과 뒤 구간을
각각 설정합니다. 임계값과 사용할 차원은 공통입니다.

- 움직임 판정 시간: 이 시간 이상 연속된 움직임을 경계로 인정합니다.
- 앞 여유 시간: 첫 유효 움직임 이전에 남겨 둘 시간입니다.
- 뒤 여유 시간: 마지막 유효 움직임 이후에 남겨 둘 시간입니다.
- 여유 시간은 삭제할 고정 길이가 아닙니다. 0초도 설정할 수 있습니다.
- 예: 앞 여유 0.5초, 뒤 여유 2초를 각각 적용할 수 있습니다.
- 중간 정지 구간은 유지하며, 에피소드별 수동 범위가 있으면 우선합니다.
- 한쪽 판정 시간에 맞는 움직임이 없으면 그쪽 끝은 자르지 않습니다.

새 Recipe에는 `start_hold_time_s`, `end_hold_time_s`, `start_margin_s`,
`end_margin_s`가 저장됩니다. 기존 Recipe에서 이 값이 없거나 null이면 기존
`hold_time_s`, `margin_s`를 양쪽에 적용하므로 이전 동작은 유지됩니다.
기존 Recipe의 설정은 자동 변경하지 않습니다. 다른 시간이 필요하면 새 Recipe를
만드세요. 배포 시 API와 CPU 작업자, 웹을 함께 업데이트해야 합니다.
