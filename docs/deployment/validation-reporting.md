# 검사 항목·결과·진행 정보

검증 화면에서 데이터셋과 검사 모드를 선택하고 검사를 시작합니다.
새 검사에는 메타데이터, 인덱스, 타임스탬프, action/state, 영상, 통계의
항목별 상태 및 실패·경고 건수가 표시됩니다. 미실행 항목은 미검사로 표시합니다.
빠른 검사는 에피소드를 샘플링하며 영상 디코딩과 통계 검사는 수행하지 않습니다.

진행 바는 처리한 에피소드 수 / 이번 검사 대상 에피소드 수입니다.
전체 실행 시간의 백분율이나 남은 시간 예측이 아닙니다. 공유 영상 파일을
처음 디코딩할 때 에피소드 비율은 정체될 수 있지만 디코딩 프레임 수가 갱신됩니다.
화면은 2초마다 현재 단계, 처리량, 경과 시간을 갱신합니다.
통계 검사 등이 남아 있으면 에피소드가 100%여도 작업은 아직 실행 중입니다.

이전 검사 기록에 저장되지 않은 항목별 결과는 소급 생성하지 않습니다.
상세 항목을 확인하려면 새 검사를 실행하세요. 연결 실패 시 마지막 확인 수치가
표시되며, 실패한 작업을 완료된 검사와 구분합니다.

배포는 웹·API·CPU 작업자를 함께 교체합니다. DB migration 9는 기존 검사 기록을
보존하면서 최신 진행 스냅샷용 progress_json 열을 추가합니다. 작업자 소유권과
유효한 lease가 확인된 경우에만 진행 정보를 갱신합니다. 원본 데이터는 변경하지 않습니다.
